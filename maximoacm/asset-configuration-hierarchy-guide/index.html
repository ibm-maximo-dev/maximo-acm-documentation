Asset Configuration Hierarchy Illustration

Overview​

The asset configuration hierarchy illustration visually represents Maximo Asset Configuration Manager's capability to define and manage complex asset structures, including models, sub-models, and installable configurations.

Visual Representation​

Figure: Hierarchical structure showing the relationship between models, sub-models, installable configurations, and components in Maximo ACM

Understanding the Hierarchy​

The illustration demonstrates four levels of asset configuration:

Level 1: Model (Blue)​

  • Color: IBM Blue (#0f62fe)
  • Represents: The top-level asset type definition
  • Purpose: Defines the engineering reference data and allowable configuration for a type of complex asset
  • Example: A locomotive model, aircraft model, or industrial equipment type

Level 2: Sub-Models (Teal)​

  • Color: Teal (#009d9a)
  • Represents: Major sub-assemblies or variants of the parent model
  • Purpose: Defines reusable components that can be installed in multiple positions or asset types
  • Example: Engine types, transmission variants, or major system modules

Level 3: Installable Configurations (Purple)​

  • Color: Purple (#8a3ffc)
  • Represents: Specific configuration options for sub-models
  • Purpose: Defines the allowable configurations that can be installed at specific positions
  • Example: Different engine configurations, optional equipment packages, or system variants

Level 4: Components/Parts (Green)​

  • Color: Green (#24a148)
  • Represents: Individual parts or items within a configuration
  • Purpose: Represents the actual serialized components tracked in the system
  • Example: Specific part numbers, serialized items, or tracked components

Key Concepts Illustrated​

  1. Hierarchical Structure: The tree diagram clearly shows parent-child relationships between different levels of asset configuration.

  2. Multiple Paths: Sub-Model A branches into two configurations (Config A1 and Config A2), demonstrating that a single sub-model can have multiple configuration options.

  3. Installable Configurations: The purple nodes represent configurations that can be installed, removed, and tracked throughout the asset lifecycle.

  4. Scalability: The structure suggests that additional sub-models, configurations, and components can be added as needed.
