SVG Design Plan: Asset Configuration Manager Hierarchy

Overview​

Creating a 200px illustration representing Maximo ACM's complex asset structure management feature, showing models, sub-models, and installable configurations.

IBM Carbon Design System Color Palette​

Based on IBM Carbon Design System guidelines:

  • Primary Blue (#0f62fe) - Parent Model (top level)
  • Teal (#009d9a) - Sub-Models (2nd level)
  • Purple (#8a3ffc) - Installable Configurations (3rd level)
  • Green (#24a148) - Components/Parts (4th level)
  • Gray 80 (#393939) - Connecting lines
  • Gray 100 (#161616) - Text labels
  • Gray 10 (#f4f4f4) - Background elements (if needed)

Visual Structure (4 Levels)​

Level 1: Parent Model (Blue)
    ├── Level 2: Sub-Model A (Teal)
    │   ├── Level 3: Config A1 (Purple)
    │   │   └── Level 4: Component (Green)
    │   └── Level 3: Config A2 (Purple)
    │       └── Level 4: Component (Green)
    └── Level 2: Sub-Model B (Teal)
        └── Level 3: Config B1 (Purple)
            └── Level 4: Component (Green)

Layout Specifications​

  • Canvas Size: 400px width × 300px height (scalable)
  • Node Size:
    • Level 1 (Model): 80px × 40px rounded rectangle
    • Level 2 (Sub-Models): 70px × 35px rounded rectangle
    • Level 3 (Configs): 60px × 30px rounded rectangle
    • Level 4 (Components): 50px × 25px rounded rectangle
  • Corner Radius: 4px (IBM Carbon standard)
  • Stroke Width: 2px for shapes, 1.5px for connecting lines
  • Vertical Spacing: 50px between levels
  • Horizontal Spacing: 40px between siblings

Element Styling​

Nodes (Rectangles)​

  • Fill: Respective color at 100% opacity
  • Stroke: Same color, slightly darker
  • Text: White (#ffffff) for contrast
  • Font: IBM Plex Sans (or system sans-serif fallback)
  • Font Size: 12px for labels
  • Font Weight: 500 (medium)

Connecting Lines​

  • Color: Gray 80 (#393939)
  • Style: Solid lines with rounded joins
  • Arrow heads: Optional, pointing downward

Labels​

  • Position: Centered within each node
  • Examples:
    • "Model" (Level 1)
    • "Sub-Model" (Level 2)
    • "Config" (Level 3)
    • "Component" (Level 4)

Key Features to Represent​

  1. Hierarchical Structure: Clear parent-child relationships
  2. Installable Configurations: Shown as distinct nodes that can be reused
  3. Multiple Paths: Demonstrate that sub-models can have multiple configurations
  4. Scalability: Visual suggests more items could be added

Accessibility Considerations​

  • High contrast ratios (WCAG AA compliant)
  • Clear visual hierarchy
  • Descriptive title and desc elements in SVG
  • Semantic structure

File Details​

  • Filename: asset-configuration-hierarchy.svg
  • Location: /docusaurus-site/static/img/
  • Format: SVG 1.1
  • Optimization: Clean, minimal code; no unnecessary groups

Usage Context​

This SVG will be used in documentation to illustrate:

  • How Maximo ACM manages complex asset structures
  • The relationship between models, sub-models, and configurations
  • The hierarchical nature of asset configuration management
  • The concept of installable and reusable configurations
