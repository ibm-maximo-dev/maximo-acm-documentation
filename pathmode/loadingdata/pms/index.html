Master PMs and PMs

Overview​

This page gives instructions, and an example of how to create Master PMs for configuration-managed Assets using the Maximo Integration Framework (MIF).

Master PMs for configuration-managed assets are associated with one or more CM Items. This enables the system to automatically create the PMs for each Asset using the relationship with the CM Item.

The example below gives examples of Master PMs for the Rapid Transit Metro Train (RTMT).

Two examples are given:

  • A yearly (12 month) inspection for the the end item (train) asset. The alert and warning intervals are set to: Alert 10 days before Due Date (a work order is automatically generated by the BDI at the alert interval). Warning Interval 5 days before due date.

  • A bogie overhaul, which is required every 500,000 KM. This task is related to two CM Items for the Motor and Trailer Bogies. The alert and warning interval are set to 5000KM and 2500KM before due count respectively.

Once the Master PMs are created (and made active) and the BDI validates the asset the system will automatically create the necessary PMs for each asset using the link to the CM Item. When PMs are created automatically they are marked as needing reviewed (ENR - Event Needs Review problem code is returned by the BDI).

The next topic describes how the PMs can be initialized using the MIF to set when they were last performed and next due.
