Design Concept

Design Concept Explanation​

The diagram below give a pictoral representation of the main design concepts of Asset Configuration Manager.

The top blue section represents the engineering reference data and data elements used to define the as-designed or allowable configuration of a complex asset.

The bottom red section represents the operational data which which is used to track and manage the as-built and as-maintained assets.

Between these two sets of data is the Build Data Intepreter (BDI). The function of the BDI is to compare the two sets of data to determine and report a configuration status and any problems with the configuration managed asset(s).

Benefits of the Design Concept​

ACM is designed to minimise the data required to define the as-designed configuration.
This is accomplished by the use of Models, Variants and sub models.
A sub model is marked as "Installable" and can be used to represent major sub assemblies used in multiple positions or asset types.

ACM also provides the ability to perform certain transactions out of chronological sequence.
This can include installation/removal of components or the entry of meter readings.
